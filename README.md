# Delirium Nova Poshta Van

Project Zomboid Build 42 mod: a Nova Poshta delivery step van.

- Vehicle script: `Base.StepVan_NovaPoshta` — the vanilla `StepVan` (`template! = StepVan`) with its own skin.
- Texture: `media/textures/Vehicles/vehicle_stepvanshell_novaposhta.png` (1024×1024, drawn on the vanilla StepVan UV layout).
- Model `Vehicle_StepVan_NoRandom` — the livery is not tinted by the random vehicle color.
- Not added to any vehicle spawn zone: spawn it through the admin vehicle menu.
